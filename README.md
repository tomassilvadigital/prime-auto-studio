# Prime Auto Studio — Demonstração inicial

## Abrir no VS Code

1. Extrai o ZIP e abre a pasta `prime-auto-studio` no VS Code.
2. Abre `index.html` no navegador. Para facilitar o desenvolvimento, podes utilizar a extensão **Live Server**.
3. Edita cada página HTML, os estilos em `css/style.css` e `css/responsive.css`, e a interação em `js/main.js`.

## Estado desta versão

- Cinco páginas navegáveis, menu adaptável a telemóvel, secções e cartões de exemplo.
- Identidade em preto, grafite e ciano.
- Fotografias **recortadas de capturas de ecrã** fornecidas na conversa; substituir por imagens originais com autorização antes da apresentação/publicação oficial.
- Logótipo enviado com fundo preto; idealmente substituir por PNG/SVG transparente fornecido pelo cliente.
- Sem formulário de contacto funcional: encaminhamento apenas para Instagram.
- Sem dados de email, telefone, morada exata ou alegações comerciais inventadas.
- O texto e a utilização dos projetos têm de ser confirmados com o cliente.
- As pré-visualizações geradas por IA são apenas referências de design, não são fotografias reais dos trabalhos.
- **Website de demonstração não oficial**, ainda não pronto para publicação comercial definitiva.

## Ficheiros

`index.html`, `servicos.html`, `projetos.html`, `sobre.html`, `contactos.html`, `css/style.css`, `css/responsive.css`, `js/main.js`, `assets/images/`.


## Contactos V2
Página com formulário exclusivamente local: prepara uma mensagem de orçamento para copiar e enviar manualmente no Instagram. Não existem envios, bases de dados ou armazenamento. Para publicação definitiva, validar contactos e conteúdos com o cliente.
